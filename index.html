O que é HTML, CSS, JS?

HTML - A Estrutura

HTML é a linguagem de marcação que estrutura todo o conteúdo da web. É o esqueleto de qualquer página web.

<button class="btn">
    Clique Aqui
</button>

Use HTML quando precisar definir:

  • Estrutura da página
  • Conteúdo semântico
  • Elementos interativos
  • Links e navegação

CSS - O Visual

CSS é a linguagem de estilo que dá vida ao HTML, permitindo criar layouts responsivos e designs atraentes.

.btn {
    background: blue;
    color: white;
    padding: 10px;
}

Com CSS você pode:

  • Criar layouts responsivos
  • Definir cores e tipografia
  • Adicionar animações
  • Personalizar componentes

JavaScript - A Interatividade

JavaScript é a linguagem de programação que torna as páginas web interativas e dinâmicas.

button.addEventListener(
    'click', 
    () => alert('Clicado!')
);

JavaScript permite:

  • Manipular o DOM
  • Criar interações dinâmicas
  • Fazer requisições AJAX
  • Validar formulários
