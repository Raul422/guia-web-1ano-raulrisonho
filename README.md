# Guia Web - Projeto Educacional

Este é um projeto educacional para ensino de desenvolvimento web, focado em HTML, CSS e JavaScript.

## Estrutura do Projeto

```
/
├── assets/        # Imagens e outros recursos
├── css/          # Arquivos de estilo
│   └── styles.css
├── js/           # Arquivos JavaScript
│   └── app.js
└── *.html        # Páginas do site
```

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts (Poppins e Inter)

## Páginas

1. Home (index.html)
2. Tecnologias (tecnologias.html)
3. Boas Práticas (boas-praticas.html)
4. Fluxo (fluxo.html)
5. Quiz (quiz.html)

## Como Executar

Abra o arquivo `index.html` em seu navegador para começar.
