# Diário de Desenvolvimento - Chat IA

Este arquivo documenta as interações com o GitHub Copilot durante o desenvolvimento do projeto.

## Primeira Fase: Estrutura Inicial

O Copilot ajudou a criar:

1. Estrutura de diretórios
   - /assets para recursos
   - /css para estilos
   - /js para JavaScript

2. Arquivos base
   - HTML semântico em todas as páginas
   - CSS com variáveis e responsividade
   - JavaScript para interatividade do menu

3. Práticas implementadas
   - HTML5 semântico
   - CSS responsivo com Flexbox e Grid
   - Acessibilidade com atributos ARIA
   - Fontes do Google Fonts
   - Menu responsivo com hambúrguer
